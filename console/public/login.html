Whoever signs in can operate the radio, so this needs the password set on the console’s computer.

Sound or microphone won’t start on this device?

Your browser warned about this page’s certificate because the console’s computer made it itself. Some phones then refuse live sound and the microphone until you tell them to trust it.

  1. Download the console’s certificate and allow it when asked.
  2. iPhone or iPad: open Settings, tap “Profile Downloaded” and install it. Then go to General, About, Certificate Trust Settings and switch it on.
  3. Android: in Settings, search for “CA certificate”, choose to install one, and pick the downloaded file.
  4. Close this tab and open the address again.

This certificate can only vouch for addresses on a home network, so trusting it does not let anyone pose as another website.
